Energy Bureau RDM Tools — Privacy Policy

Last updated: 31 August 2026

Summary: Energy Bureau RDM Tools processes Resource Data Management (RDM) website information locally in Chrome to provide engineering tools. It does not read Chrome-saved passwords, does not sell user data, does not use advertising or analytics, and does not send RDM engineering data to an Energy Bureau or third-party server.

1. Purpose of the extension

Energy Bureau RDM Tools is an engineering extension intended for authorised users working with Resource Data Management ActiveFM and Data Manager. Its purpose is to provide client-aware engineering tools alongside RDM, including preparation and local generation of TDB programmes.

2. Information the extension accesses

When required for an engineering tool, the extension may access information displayed by or returned from Resource Data Management websites under *.resourcedm.com. This can include:

  • the currently signed-in RDM client, such as M&S or Asda;
  • site/store number, site name and Data Manager host;
  • ActiveFM Site List and System Check information;
  • Data Manager Device Information and live controller information;
  • RDM page URLs and tab relationships needed to associate an ActiveFM site with its Data Manager tab;
  • engineering selections made by the user inside the extension, such as EHR case inclusion, Phase 2 selection and pack assignment.

3. Passwords and authentication

The extension does not read passwords from Chrome Password Manager and does not request that Chrome disclose saved passwords. It does not store ActiveFM or Data Manager passwords.

Users authenticate through the normal RDM webpages. The extension may inspect the already-loaded RDM page to determine whether the user is signed in, for example by detecting the normal Login or Logout state.

4. How information is used

RDM information is used only to provide the extension's engineering functionality. For example, M&S EHR functionality can combine ActiveFM System Check information with Data Manager controller information so the user can review cases and generate a TDB programme.

The extension does not use RDM information for advertising, behavioural profiling, credit decisions or unrelated purposes.

5. Local processing and storage

Version 1 of Energy Bureau RDM Tools performs its programme-generation and RDM data processing locally in the user's Chrome browser.

Chrome session storage may be used to remember temporary information such as the currently identified RDM client and the association between ActiveFM and Data Manager tabs. This information is intended to persist only for the relevant browser session and is not used as a user-tracking system.

6. Downloads and generated files

Generated TDB programmes, build reports or exported engineering snapshots are created only when the user explicitly requests them. Files are saved locally using Chrome's download or file-selection functionality.

7. External transmission and sharing

Energy Bureau RDM Tools does not send RDM engineering data, credentials, analytics or browsing information to an Energy Bureau server or to a third-party analytics or advertising service.

Requests required to obtain live engineering information are made only to the relevant Resource Data Management websites used to provide the requested RDM functionality.

8. Sale of data

The extension does not sell user data or RDM engineering data.

9. Remote code

The extension does not download and execute remote programme code. Executable extension logic and TDB-generation logic are packaged with the extension. RDM HTML, XML and other responses are treated as data and are not executed as downloaded extension code.

10. Data retention

Temporary client, site and tab-association information is stored only as needed for the active Chrome session. Engineering data loaded into the side panel is held locally while required for the current task. A user can explicitly save generated output files to their own computer.

11. Security

The extension limits its website access to Resource Data Management domains required for its functionality and does not request access to unrelated websites. Authentication remains handled by the normal RDM websites.

12. Changes to this policy

This policy may be updated when Energy Bureau RDM Tools gains new functionality or when its data-handling behaviour changes. The updated date at the top of this page will be changed when the policy is revised.

13. Contact

For questions about Energy Bureau RDM Tools or this privacy policy, contact the Energy Bureau team through the normal internal City Facilities Management support or management channels.
